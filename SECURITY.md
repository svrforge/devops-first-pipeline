# Security and scope

This is a local learning project, not production software. Do not store personal data, real credentials, kubeconfigs or Terraform state in examples. Never expose a Jenkins controller or Docker daemon just to complete a lesson.

If you find a suspected vulnerability, use GitHub private vulnerability reporting when available. Otherwise describe the issue without exploitation details or secrets and ask the maintainer for a private reporting route. Do not post active credentials publicly.

CI currently checks behavior, course integrity, container startup and non-root execution. It does not prove the absence of vulnerabilities. Real leaked credentials require revocation/rotation even after removing the commit.
