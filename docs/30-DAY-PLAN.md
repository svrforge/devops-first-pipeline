# 30-day practice plan

45–60 minutes per day is a suggested pace, not a deadline. Repeat a day until its proof is clear. All core exercises are local; Jenkins and kind need additional setup.

| Days | Focus | Evidence to keep |
|---|---|---|
| 1–2 | Setup + module 01 | Passing test output and explanation of one assertion |
| 3–4 | Linux/processes | Start/stop app, logs, environment-variable example |
| 5–6 | Git | Branch, focused commit and readable diff |
| 7–8 | Networking | Explain refused connection vs HTTP 404 |
| 9–10 | Tests | Red/green exercise with a meaningful assertion |
| 11–13 | Docker | Build, inspect UID/health, explain host vs container port |
| 14–15 | CI | PR with successful checks for the exact commit |
| 16–17 | Jenkins | Stage outputs on a dedicated learning agent |
| 18–20 | Kubernetes | Named-context rollout and failure diagnosis |
| 21–22 | Terraform | Plan/apply/no-change plan and state explanation |
| 23–24 | Observability | Probe observations and logs with timestamps |
| 25–26 | Incident exercise | Completed postmortem and verified recovery |
| 27 | Security/cloud planning | IAM/network/cost worksheet, no provisioning required |
| 28–29 | Capstones | Evidence against the three rubrics |
| 30 | Explain and review | Demo to another learner and fix unclear instructions |

Daily reflection: What changed? What evidence proves it? What failed? How did I recover? What is still unknown?
