# 03 · Git மற்றும் இணைந்து வேலை

[Course index](README.md) · [English](../en/03.md) · [தமிழ்](../ta/03.md)

## Understand

Git மாற்றங்களை commit ஆக சேமிக்கிறது. Branch மூலம் main-ஐ பாதிக்காமல் வேலை செய்யலாம். PR review செய்ய உதவும். Commit முன்னால் diff பார்க்கவும்; தேவையான files மட்டும் stage செய்யவும்.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
git status
git switch -c learning/first-change
git diff
```

## Verify

சரிபார்ப்பு: You are on learning/first-change; main has not moved. Make a documentation edit, inspect diff, then commit it.

## Break, diagnose, recover

பயிற்சி மற்றும் recovery: If you edited the wrong file, inspect git diff first. Copy wanted work to a safe place before using any restore command.
