# 08 · Jenkins pipeline

[Course index](README.md) · [English](../en/08.md) · [தமிழ்](../ta/08.md)

## Understand

Jenkins controller வேலை ஒருங்கிணைக்கும்; agent stages இயக்கும். Agent-ல் தேவையான Python/Docker இருக்கவேண்டும். Docker access அதிக அதிகாரம் தருவதால் dedicated lab agent பயன்படுத்தவும். GitHub CI மற்றும் Jenkins ஒரே checks பயன்படுத்துகின்றன.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
python -m unittest discover -s tests -v
bash scripts/container-check.sh devops-first-pipeline:local
```

## Verify

சரிபார்ப்பு: Follow docs/JENKINS.md. All stages are green on your dedicated Linux agent.

## Break, diagnose, recover

பயிற்சி மற்றும் recovery: Use an agent without Docker and inspect the command-not-found failure. Fix the agent, not the verification stage.
