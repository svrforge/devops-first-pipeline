# 01 · DevOps மனப்பாங்கு

[Course index](README.md) · [English](../en/01.md) · [தமிழ்](../ta/01.md)

## Understand

DevOps என்பது development மற்றும் operations இணைந்து பொறுப்பேற்பது. சிறிய மாற்றம், உடனடி feedback, சோதனை, recovery முக்கியம். Tool பெயர்களை மனப்பாடம் செய்வதைவிட ஒரு service-ஐ பாதுகாப்பாக நடத்த கற்றுக்கொள்வோம்.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
python -m unittest discover -s tests -v
```

## Verify

சரிபார்ப்பு: All tests finish with OK. Identify which test proves that unknown routes return 404.

## Break, diagnose, recover

பயிற்சி மற்றும் recovery: Change the greeting in app.py only. Observe a failing assertion. Restore the greeting before continuing.
