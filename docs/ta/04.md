# 04 · Network மற்றும் HTTP

[Course index](README.md) · [English](../en/04.md) · [தமிழ்](../ta/04.md)

## Understand

Request வரும்போது name resolution, port connection, HTTP response என படிகள் உள்ளன. localhost உங்கள் கணினி. Connection வந்தாலே app சரியாக வேலை செய்கிறது என்று அர்த்தமில்லை. 200 success; 404 route இல்லை. இந்த local lab-ல் HTTP மட்டும்.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
python app.py
```

## Verify

சரிபார்ப்பு: Open http://localhost:8000/health and then /missing. Compare 200 vs 404 using browser developer tools or curl -i.

## Break, diagnose, recover

பயிற்சி மற்றும் recovery: Request http://localhost:8001/health while the service uses 8000. Explain connection refused versus an HTTP 404.
