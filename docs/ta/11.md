# 11 · Observability மற்றும் incident response

[Course index](README.md) · [English](../en/11.md) · [தமிழ்](../ta/11.md)

## Understand

Logs நிகழ்வுகளை சொல்கின்றன; metrics அளவுகளை சொல்கின்றன; traces request பயணத்தை இணைக்கும். Incident-ல் symptom, scope, recent change, mitigation, recovery verification, timeline ஆகியவற்றை பதிவு செய்யவும். Evidence இல்லாமல் அனைத்தையும் restart செய்யாதீர்கள்.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
docker compose logs --tail=30 app
python labs/observability/probe.py http://127.0.0.1:8000/health
```

## Verify

சரிபார்ப்பு: The probe reports HTTP status and elapsed time. Use labs/incident/POSTMORTEM.md to record your experiment.

## Break, diagnose, recover

பயிற்சி மற்றும் recovery: Stop only your Compose app. Observe probe failure, start it again, verify recovery and capture the two timestamps.
