## Understand

IaC தேவையான infrastructure நிலையை code-ல் சொல்கிறது. Plan மாற்றங்களை முன்காட்டும்; apply செயல்படுத்தும். இந்த terraform_data lab cloud resource உருவாக்காது. State-ஐ commit செய்யவேண்டாம்; real state sensitive values கொண்டிருக்கலாம்.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
terraform -chdir=labs/terraform init
terraform -chdir=labs/terraform plan
terraform -chdir=labs/terraform apply
```

## Verify

சரிபார்ப்பு: Review the plan interactively. Output shows the service name and replicas. A second plan says no changes.

## Break, diagnose, recover

பயிற்சி மற்றும் recovery: Change replicas from 2 to 3 via -var="replicas=3" in plan; explain the proposed input update before applying.
