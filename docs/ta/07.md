# 07 · CI மற்றும் பாதுகாக்கப்பட்ட மாற்றங்கள்

[Course index](README.md) · [English](../en/07.md) · [தமிழ்](../ta/07.md)

## Understand

CI ஒவ்வொரு change-ஐ சோதிக்கும். Required checks fail ஆனால் main merge தடுக்கப்படும். Green pipeline எல்லா பாதுகாப்பும் சரி என்று சொல்லாது; configure செய்த checks மட்டும் pass. Error மறைத்து green காட்டக்கூடாது.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
python -m unittest discover -s tests -v
python scripts/validate_course.py
```

## Break, diagnose, recover

பயிற்சி மற்றும் recovery: Push a failing test on your learning branch. Confirm the PR check fails, then fix it and confirm the newer commit is green.
