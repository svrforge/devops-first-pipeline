# 02 · Linux மற்றும் process

## Understand

Shell command-ஐ இயக்கும்; process என்பது இயங்கும் நிரல். Path கோப்பை குறிக்கும். Environment variable மூலம் config கொடுக்கலாம். stdout/stderr logs-க்கு பயன்படும். இந்த repository உள்ளே மட்டும் practice செய்யவும்.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
pwd
ls
python --version
python app.py
```

## Verify

சரிபார்ப்பு: The app prints Listening on 0.0.0.0:8000. In another terminal call /health. Ctrl+C stops the foreground process.

## Break, diagnose, recover

பயிற்சி மற்றும் recovery: Start a second copy on the same port. Read Address already in use; stop the second copy and keep only your intended process.
