# 06 · Docker image மற்றும் container

[Course index](README.md) · [English](../en/06.md) · [தமிழ்](../ta/06.md)

## Understand

Image என்பது runtime உடன் app package. Container அதன் running instance. EXPOSE host port திறக்காது; port mapping தேவை. Running status-ஐவிட health check service behavior பார்க்கும். குறைந்த privileges பயன்படுத்துவது நல்ல நடைமுறை.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
docker build -t devops-first-pipeline:local .
bash scripts/container-check.sh devops-first-pipeline:local
docker compose up -d
```

## Verify

சரிபார்ப்பு: Container health, response and non-root checks pass. Open localhost:8000, then docker compose down after the lab.

## Break, diagnose, recover

பயிற்சி மற்றும் recovery: Temporarily map host 8001 to container 8000. The internal health check should still pass; your browser must use host 8001.
