## In simple words

Explain why an unchanged second plan should show no change. Start with the short explanation below. Read the new-word meaning, follow one part at a time, and try the activity only when the idea makes sense. You do not need to memorize a list of tool names.

State links configuration to managed objects. A second plan after a successful unchanged apply should show no changes. Real state can contain sensitive data and must not be committed. Drift is a difference between expected managed state and external reality; our local data lab illustrates state transitions, not a full cloud drift experiment.
