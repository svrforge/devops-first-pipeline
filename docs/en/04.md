## In simple words

Start a program, make one request and stop the program you started. Start with the short explanation below. Read the new-word meaning, follow one part at a time, and try the activity only when the idea makes sense. You do not need to memorize a list of tool names.

A program on disk becomes a process when it runs. The process listens on a port so other programs can connect. Environment variables provide runtime configuration. Two processes usually cannot bind the same address and port at once. A stopped process cannot answer requests even if its source files still exist.

## Part 1: Start

A program is a saved set of instructions. A process is that program while it is running. Extract the sample project ZIP, open its folder, then open a terminal in that folder. Run python app.py. Use py or python3 if that was your working Python command on Day 3.

**New word — Process:** A program while it is running.

**Example:** A recipe is not a running kitchen. A process is the kitchen at work; a port is a service counter.

## Part 2: Request

While the program is running, open http://localhost:8000/health in your browser. The program answers the browser request. A program that answers other programs is acting as a server. localhost means your own computer.

**New word — Server:** A computer or program that answers requests from other programs.

**Example:** Open localhost:8000/health in a browser or a second terminal.

## Part 3: Configure

The number 8000 is a port: a numbered connection point for the program. Keep the default today. Later you can stop the app, change its port, and use the new number in the browser URL.

**New word — Port:** A numbered connection point used to reach a program.

**Example:** Stop with Ctrl+C. In Bash run PORT=8001 python app.py, then use localhost:8001.

## Part 4: Stop

Click the terminal running your app and press Ctrl+C. This asks your foreground program to stop. Refresh the browser. The app cannot answer now because its process has stopped. Start it again to restore the response.

**New word — Environment variable:** A named value a program can read when it starts.

**Example:** Use Ctrl+C on your own foreground service and verify requests stop working.

## What you should notice

Your browser shows {"status": "ok"} while the program runs. After Ctrl+C, refreshing the page fails. Starting the app again restores the response. These observations explain why instructions saved on disk are different from a running process.
