# Day 4 — Processes, ports and configuration

[All days](README.md) · [Animated classroom](../../academy/index.html#day=4)

## The idea

A program on disk becomes a process when it runs. The process listens on a port so other programs can connect. Environment variables provide runtime configuration. Two processes usually cannot bind the same address and port at once. A stopped process cannot answer requests even if its source files still exist.

## A familiar example

A recipe is not a running kitchen. A process is the kitchen at work; a port is a service counter.

## Walk through it

### 1. Start

Run python app.py. The foreground process keeps this terminal occupied.

### 2. Request

Open localhost:8000/health in a browser or a second terminal.

### 3. Configure

Stop with Ctrl+C. In Bash run PORT=8001 python app.py, then use localhost:8001.

### 4. Stop

Use Ctrl+C on your own foreground service and verify requests stop working.

## Try it yourself

Run from the repository root. Read comments and prerequisites first.

```bash
python app.py
```

## Expected evidence

The terminal shows Listening on 0.0.0.0:8000; /health returns status ok. PowerShell configuration uses $env:PORT="8001" before starting.

## Break, diagnose, recover

Start a second copy on port 8000. Diagnose Address already in use, then stop only the extra process you started.
