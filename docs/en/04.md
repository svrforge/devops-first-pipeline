# 04 · Networking and HTTP

[Course index](README.md) · [English](../en/04.md) · [தமிழ்](../ta/04.md)

## Understand

A request follows a chain: name resolution, connection to a port, HTTP request and response. localhost refers to your own machine. A successful TCP connection does not prove correct application behavior. HTTP 200 means a successful request here; 404 means an unknown route. TLS encrypts transport; this local lab intentionally uses HTTP only.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
python app.py
```

## Verify

Open http://localhost:8000/health and then /missing. Compare 200 vs 404 using browser developer tools or curl -i.

## Break, diagnose, recover

Request http://localhost:8001/health while the service uses 8000. Explain connection refused versus an HTTP 404.
