## The idea

Automation cannot rely on a person noticing a red line. Programs return exit codes: zero conventionally means success, nonzero means failure. stdout and stderr carry output, but a message that says success is not the same as an actual successful exit. Shell pipelines need deliberate error handling.

## A familiar example

An alarm that prints a warning but reports everything is fine cannot protect a building.
