# Day 5 — Exit codes, logs and safe shell habits

[All days](README.md) · [Open the lesson](https://svrforge.github.io/devops-first-pipeline/#day=5)

## Today’s goal

Read a result and explain how a command signals success or failure.

**Before you start:** Day 3: you can run Python. Use py or python3 if that is your working command. No sample project or Docker required.

**Tools:** Python and your terminal

Programs can show messages and can also return a result number. That number helps another program decide whether the work succeeded. Today you will compare one successful instruction with one deliberate failure. You do not need Docker, Git or tests yet.

## Part 1: Display a normal message

Run the first print command in the activity. Python displays Starting my practice. This visible message is output. A program can print several messages as it works.

**Output:** Something a program displays or produces.

Example: A message saying Starting does not prove that the rest of the program finished.

## Part 2: Ask whether it finished successfully

Immediately after that command, inspect the exit code. In PowerShell type $LASTEXITCODE. In Bash or macOS Terminal type echo $?. A successful run usually returns 0.

**Exit code:** A number returned when a program finishes. Zero usually means success.

Example: Read the result number separately from the sentence printed by the program.

## Part 3: Create a harmless failure

Run the second Python command, which deliberately exits with code 7. It changes no files. Inspect the exit code immediately afterward using the command for your terminal.

**Nonzero:** Any number other than zero; commonly used to signal failure.

Example: The result is 7 instead of 0. Another program can use that number to know the work failed.

## Part 4: Read the message and the result

A printed message helps a person understand an event. An exit code helps automation decide what to do next. Look at both. Later, you will use recorded messages, called logs, to investigate problems.

**Log:** A recorded message about something a program did.

Example: A script that prints All good but returns a failure code needs investigation. A message and a result number are different evidence.

## Small activity

```text
python -c "print('Starting my practice')"
# Now inspect the exit code:
# PowerShell: $LASTEXITCODE
# Bash/macOS Terminal: echo $?

python -c "raise SystemExit(7)"
# Inspect the exit code again using your terminal’s command.
```

## What you should notice

The print command returns 0. The deliberate SystemExit command returns 7. You can explain why displaying a sentence and finishing successfully are different things.

## Think about this

Replace 7 with 3 in the deliberate exit command. Predict the next result number before running it. This is a controlled local exercise; you are not breaking your computer.
