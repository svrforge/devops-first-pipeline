## Understand

Tests are executable examples of the contract. These tests start a real HTTP server on a free local port and call it over HTTP. That catches routing, response serialization and status-code mistakes without needing external services. Keep tests deterministic: no public APIs, no hardcoded occupied ports and no dependence on execution order.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
python -m unittest discover -s tests -v
```

## Verify

Five HTTP tests and the course tests pass. Explain why an ephemeral port reduces collisions.
