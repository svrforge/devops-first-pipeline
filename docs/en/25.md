## In simple words

Use one log message and one measurement to explain what happened. Start with the short explanation below. Read the new-word meaning, follow one part at a time, and try the activity only when the idea makes sense. You do not need to memorize a list of tool names.

Logs record events; metrics summarize measurements; traces connect work across components. Our one-request probe measures HTTP status and elapsed time. A single observation is not an availability SLO. Define a window and population before calculating reliability percentages.
