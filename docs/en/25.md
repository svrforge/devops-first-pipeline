# Day 25 — Observe: logs, metrics and traces

[All days](README.md) · [Animated classroom](../../academy/index.html#day=25)

## The idea

Logs record events; metrics summarize measurements; traces connect work across components. Our one-request probe measures HTTP status and elapsed time. A single observation is not an availability SLO. Define a window and population before calculating reliability percentages.

## A familiar example

A receipt, a daily sales chart and an order journey answer different questions.

## Walk through it

### 1. Log

Read app request logs to see individual events.

### 2. Measure

Run a probe and inspect status plus duration.

### 3. Scope

Recognize that one successful request does not describe the last month.

### 4. Correlate

Record time, version and action when investigating a change.

## Try it yourself
