# Day 26 — Run an incident without guessing

[All days](README.md) · [Animated classroom](../../academy/index.html#day=26)

## The idea

Observe the symptom and affected scope, inspect recent changes, select a safe mitigation, then verify recovery. Keep a timeline and distinguish facts from hypotheses. Restarting everything can erase evidence or increase impact. Use only this disposable local environment for failure drills.

## A familiar example

A doctor first identifies symptoms and severity before treating every organ at once.

## Walk through it

### 1. Detect

Record which request fails and when.

### 2. Diagnose

Compare process, port, logs and recent changes.

### 3. Mitigate

Choose the smallest safe action supported by evidence.

### 4. Verify

Repeat the user-visible check and record recovery time.
