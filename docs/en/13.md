## In simple words

Explain an image and build one locally. Start with the short explanation below. Read the new-word meaning, follow one part at a time, and try the activity only when the idea makes sense. You do not need to memorize a list of tool names.

An image contains the application and its runtime filesystem. Dockerfile instructions describe how to build it. An image is not a running server until a container starts. Build context matters: only send the files needed, and exclude local state or credentials.

## Part 1: Base

FROM chooses a runtime image. Upstream changes can affect future builds.

**New word — Docker:** A tool for packaging and running applications in containers.

## Small activity

```bash
docker build -t devops-first-pipeline:local .
docker image inspect devops-first-pipeline:local
```

## What you should notice

The image is built and inspect shows the configured command and non-root user. Docker must be running first.
