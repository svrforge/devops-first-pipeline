# 07 · CI and protected changes

[Course index](README.md) · [English](../en/07.md) · [தமிழ்](../ta/07.md)

## Understand

Continuous integration checks each proposed change. This workflow checks Python versions, course content and a real Docker container. Required checks stop known failures from merging into main. A passing pipeline proves only the configured checks; it is not a security certificate or a production deployment. Never hide errors with continue-on-error to keep a badge green.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
python -m unittest discover -s tests -v
python scripts/validate_course.py
```

## Break, diagnose, recover

Push a failing test on your learning branch. Confirm the PR check fails, then fix it and confirm the newer commit is green.
