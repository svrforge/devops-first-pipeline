# Day 2 — Meet files, folders and the terminal

[All days](README.md) · [Open the lesson](https://svrforge.github.io/devops-first-pipeline/#day=2)

## Today’s goal

Find a file, make a practice folder and run your first harmless command.

**Before you start:** Day 1. A Windows, macOS or Linux computer. No Git or Python required.

**Tools:** Your file manager and built-in terminal

An app is stored in files on a computer. Folders keep those files together. A terminal is a window where you type instructions instead of clicking buttons. Today, learn these three ideas before installing development tools.

## Part 1: Find a file

Open your normal file manager: File Explorer on Windows or Finder on macOS. A photo or text document is a file. Its name helps you identify it. You do not need an app project yet.

**File:** One saved item on a computer, such as a document, photo or program.

Example: Find one document you already know. Notice its name and the folder containing it.

## Part 2: Make a learning folder

Create a new folder called DevOps-Learning in a location you can find again. A folder groups related files. This is your practice space; do not use a work project or confidential folder.

**Folder:** A place that groups files and other folders.

Example: You can open DevOps-Learning and explain where it is saved.

## Part 3: Open a terminal

On Windows, open PowerShell from the Start menu. On macOS, open Terminal. On Linux, open your terminal app. Opening this window does not change your files. You will type only a simple display command today.

**Terminal:** A window where you can type commands for your computer to carry out.

Example: The window shows a place where you can type. That is the prompt.

## Part 4: Ask where you are

Type pwd and press Enter. It prints the current folder location in PowerShell, macOS Terminal or a typical Linux shell. This command asks a question; it does not delete or edit anything.

**Command:** An instruction you type and run by pressing Enter.

Example: Read the printed location. It may be your home folder rather than DevOps-Learning. That is normal.

## Small activity

```text
pwd
```

## What you should notice

You found a file, created a practice folder, opened a terminal and read the folder location printed by pwd. These are four separate actions; take them one at a time.

## Think about this

Compare clicking a folder in the file manager with looking at the terminal location. They do not automatically move together. Explain why you must know which folder the terminal is using.
