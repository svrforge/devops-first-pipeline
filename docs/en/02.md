# 02 · Linux and processes

[Course index](README.md) · [English](../en/02.md) · [தமிழ்](../ta/02.md)

## Understand

A shell runs commands; a process is a running program. Paths identify files, environment variables configure processes, stdout and stderr carry logs. Exit code 0 indicates success by convention. Work inside this disposable repository and inspect before changing files. Linux lab commands work in Bash on Linux, macOS or WSL.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
pwd
ls
python --version
python app.py
```

## Verify

The app prints Listening on 0.0.0.0:8000. In another terminal call /health. Ctrl+C stops the foreground process.

## Break, diagnose, recover

Start a second copy on the same port. Read Address already in use; stop the second copy and keep only your intended process.
