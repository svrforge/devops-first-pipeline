# 12 · Security, cloud and capstone

[Course index](README.md) · [English](../en/12.md) · [தமிழ்](../ta/12.md)

## Understand

Least privilege means granting only the access needed for a task. Keep secrets outside source control, review changes and limit public exposure. Cloud adds networking, IAM, cost and shared responsibility. Our OCI guide is a planning exercise, not an automatic cloud deployment. Complete the capstone by showing tested behavior, container evidence, a PR, an incident timeline and a recovery explanation.
