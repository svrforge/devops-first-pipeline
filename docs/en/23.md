## In simple words

Preview a local resource change before applying it. Start with the short explanation below. Read the new-word meaning, follow one part at a time, and try the activity only when the idea makes sense. You do not need to memorize a list of tool names.

Terraform compares declared configuration and recorded state to propose changes. Plan previews; apply performs. The built-in terraform_data lab creates no cloud compute. That isolates the workflow so you can learn without credentials or bills. Real infrastructure requires separate approvals and controls.

## Small activity

```bash
terraform -chdir=labs/terraform init
terraform -chdir=labs/terraform validate
terraform -chdir=labs/terraform plan
```

## What you should notice

The plan proposes a local terraform_data object; there are no OCI credentials or cloud resources.

## Think about this

Plan with replicas=0 and confirm input validation rejects it. Use replicas=3 to inspect a valid change.
