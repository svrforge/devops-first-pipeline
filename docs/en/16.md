## In simple words

Run the app with only the powers it needs. Start with the short explanation below. Read the new-word meaning, follow one part at a time, and try the activity only when the idea makes sense. You do not need to memorize a list of tool names.

Compose describes local service configuration. It is useful for repeatable startup without remembering a long docker run command. This lab limits exposure to loopback, drops capabilities and uses a read-only filesystem. Those controls reduce privileges but do not replace secure application design.

## Part 1: Validate

docker compose config checks the effective configuration.

**New word — Capability:** One specific extra power a Linux process may have.

**Example:** A repeatable setup checklist is better than remembering every switch by hand.

## Part 2: Restrict

The mapping binds to 127.0.0.1 so the lab is not intentionally exposed on the LAN.

**New word — Read-only:** The app can read files but cannot change that filesystem.

## Part 3: Reduce

Read-only filesystem and dropped capabilities limit unneeded runtime powers.

**New word — Loopback:** A network address that points back to your own machine.
