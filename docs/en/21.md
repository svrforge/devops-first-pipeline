[All days](README.md) · [Animated classroom](../../academy/index.html#day=21)

## The idea

A Deployment describes the desired number of pods. Kubernetes reconciles actual state toward that declaration. A Service selects eligible pods through labels. A namespace and context determine where commands act; always use the named local context in this course.

## A familiar example

A manager requests two service counters; the system keeps trying to maintain two staffed counters.
