## In simple words

Describe a pod and a Deployment using your local example. Start with the short explanation below. Read the new-word meaning, follow one part at a time, and try the activity only when the idea makes sense. You do not need to memorize a list of tool names.

A Deployment describes the desired number of pods. Kubernetes reconciles actual state toward that declaration. A Service selects eligible pods through labels. A namespace and context determine where commands act; always use the named local context in this course.
