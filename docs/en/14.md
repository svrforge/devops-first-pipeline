## In simple words

Run a container and reach it using the right host port. Start with the short explanation below. Read the new-word meaning, follow one part at a time, and try the activity only when the idea makes sense. You do not need to memorize a list of tool names.

A container has its own runtime view. The host port and container port are separate. Publishing 8001:8000 means the browser uses host 8001 while the app still listens on container 8000. Logs describe what the process emitted; they are often the first evidence for a startup failure.

## Part 1: Start

Compose builds/starts the local app with a loopback-only port mapping.

**New word — Host:** The computer running Docker.

**Example:** A building can direct door 8001 to counter 8000 inside.

## Part 2: Inspect

Use compose ps to see status before assuming it is ready.

**New word — Port mapping:** A connection from a port on the host to a port inside a container.

**Example:** Use compose ps to see status before assuming it is ready.

## Small activity

```bash
docker compose up --build -d
docker compose ps
docker compose logs --tail=30 app
docker compose down
```

## What you should notice

The local endpoint works while Compose is up, and stops responding when the container is down.

## Think about this

Temporarily change only the host mapping to 8001:8000. Use localhost:8001 and then restore the file.
