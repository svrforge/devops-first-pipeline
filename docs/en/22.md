## In simple words

Explain which check controls traffic and which can trigger a restart. Start with the short explanation below. Read the new-word meaning, follow one part at a time, and try the activity only when the idea makes sense. You do not need to memorize a list of tool names.

Readiness decides whether a pod is eligible for service traffic. Liveness can cause a container restart when its probe fails. Bad probe settings can worsen an incident. A rollout must be observed; applying YAML does not guarantee the new version is healthy.
