# 11 · Observability and incident response

[Course index](README.md) · [English](../en/11.md) · [தமிழ்](../ta/11.md)

## Understand

Logs describe events, metrics summarize measurements and traces connect work across services. Availability should be measured from the user perspective. During an incident: observe symptoms, establish scope, inspect recent changes, mitigate safely, verify recovery and record a timeline. Do not restart everything before collecting enough evidence to understand the failure.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
docker compose logs --tail=30 app
python labs/observability/probe.py http://127.0.0.1:8000/health
```

## Verify

The probe reports HTTP status and elapsed time. Use labs/incident/POSTMORTEM.md to record your experiment.

## Break, diagnose, recover

Stop only your Compose app. Observe probe failure, start it again, verify recovery and capture the two timestamps.
