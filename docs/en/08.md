## In simple words

Tell the difference between a connection failure and a missing web page. Start with the short explanation below. Read the new-word meaning, follow one part at a time, and try the activity only when the idea makes sense. You do not need to memorize a list of tool names.

A browser request involves name lookup, a network connection and an application response. localhost refers to the machine making the request. The port selects a listening service. HTTP status describes the application result after a connection exists. Connection refused and HTTP 404 are different layers of failure.

## Part 1: Address

The URL names a destination and optional port.

**New word — Client:** The program asking for something, such as your browser.

**Example:** Reaching the shop door is different from finding the product you asked for.

## Part 2: Connect

The client tries to connect to a process listening at that address.

**New word — HTTP:** Rules a browser and a web server use to exchange requests and responses.

**Example:** The client tries to connect to a process listening at that address.

## Part 3: Request

The client sends a method and path such as GET /health.

**New word — Status code:** A response number: 200 means success here; 404 means the requested route was not found.

**Example:** The client sends a method and path such as GET /health.

## Part 4: Respond

The server returns status, headers and a body. Inspect all three when debugging.

**New word — Status code:** A response number: 200 means success here; 404 means the requested route was not found.

**Example:** The server returns status, headers and a body. Inspect all three when debugging.
