# 08 · Jenkins pipelines

[Course index](README.md) · [English](../en/08.md) · [தமிழ்](../ta/08.md)

## Understand

Jenkins executes stages on an agent. The controller coordinates work; the agent needs the tools used by the pipeline. A Jenkins container does not automatically contain Docker or Python. Docker daemon access is powerful, so use a dedicated lab agent. This repo reuses the same test and container verification commands instead of inventing a second definition of success.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
python -m unittest discover -s tests -v
bash scripts/container-check.sh devops-first-pipeline:local
```

## Verify

Follow docs/JENKINS.md. All stages are green on your dedicated Linux agent.

## Break, diagnose, recover

Use an agent without Docker and inspect the command-not-found failure. Fix the agent, not the verification stage.
