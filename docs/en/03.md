# Day 3 — Your first tiny Python program

[All days](README.md) · [Open the lesson](https://svrforge.github.io/devops-first-pipeline/#day=3)

## Today’s goal

Run one Python instruction and explain the output.

**Before you start:** Day 2: you can open a terminal. Download Python only from python.org.

**Tools:** Python 3.11 or newer

Python is a language people use to write instructions for a computer. You do not need to learn the whole language today. Install it from the official source, check that it starts, and ask it to print one sentence.

## Part 1: Know what Python is

Different human languages express ideas. Programming languages express instructions for computers. Python is one of them. In this course it runs our small practice app.

**Programming language:** A way to write instructions that a computer can follow.

Example: The instruction print("Hello") tells Python to display Hello.

## Part 2: Install it carefully

Use the official Python downloads page linked in the activity below. Choose a supported Python 3 version, 3.11 or newer. On Windows, use the installer option to add Python to PATH if offered. Close and reopen your terminal afterward.

**Install:** Put a program on your computer so you can run it.

Example: PATH is a list of places your computer searches when you type a program name.

## Part 3: Check the version

Type python --version. If Windows cannot find it, try py --version. On macOS or Linux, try python3 --version. Use whichever command successfully reports Python 3.11 or newer in later commands.

**Version:** A number that identifies a particular edition of a program.

Example: Python 3.12.x is one acceptable result. The last number can differ.

## Part 4: Print a sentence

Run the one-line example in the activity. The -c option means run the instructions inside the quotes. print displays a message. This creates no cloud service and needs no account.

**Output:** The result a program displays or produces.

Example: The output should be Hello, I am learning DevOps. Your computer just followed your first Python instruction.

## Small activity

```text
python --version
python -c "print('Hello, I am learning DevOps')"
```

## What you should notice

The first command shows Python 3.11 or newer. The second prints Hello, I am learning DevOps. If you used py or python3 for the first command, use that same name for the second.

## Think about this

Change only the sentence inside the quotes and run it again. Then leave out a closing quote once, read the error, and restore it. An error is feedback about the instruction, not a reason to reinstall everything.
