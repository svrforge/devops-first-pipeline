# 03 · Git and collaboration

[Course index](README.md) · [English](../en/03.md) · [தமிழ்](../ta/03.md)

## Understand

Git stores snapshots as commits. A branch lets you prepare a change without moving main. A pull request makes that change reviewable. Inspect diff before staging, and stage specific files so unrelated local content is not included. Forks let visitors contribute without write access to this account.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
git status
git switch -c learning/first-change
git diff
```

## Verify

You are on learning/first-change; main has not moved. Make a documentation edit, inspect diff, then commit it.

## Break, diagnose, recover

If you edited the wrong file, inspect git diff first. Copy wanted work to a safe place before using any restore command.
