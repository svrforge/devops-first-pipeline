## The idea

A path tells the shell where a file is. Relative paths start at your current directory; absolute paths start at the filesystem root. Read permission allows inspection, write allows changes, and execute allows running a file directly. Reading a script before executing it is a useful habit.

## A familiar example

A street address and a direction from your current room both identify places, but only one is independent of where you stand.
