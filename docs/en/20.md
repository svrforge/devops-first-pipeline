## In simple words

Identify the running version and describe a safe return to an earlier version. Start with the short explanation below. Read the new-word meaning, follow one part at a time, and try the activity only when the idea makes sense. You do not need to memorize a list of tool names.

A release needs traceability from source commit to built artifact to running version. Rebuilding the same mutable tag is weaker evidence than recording an immutable digest. Rollback should be a deliberate return to a known version followed by behavior verification. Our sample version variable demonstrates identification, not a production release system.
