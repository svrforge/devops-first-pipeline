# 06 · Docker images and containers

[Course index](README.md) · [English](../en/06.md) · [தமிழ்](../ta/06.md)

## Understand

An image packages files and runtime; a container is an instance of that image. Build time and runtime are different. EXPOSE documents a port but does not publish it. A health check evaluates service behavior, while running only says the process has not exited. Non-root UID, dropped capabilities and a read-only filesystem reduce unnecessary privileges.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
docker build -t devops-first-pipeline:local .
bash scripts/container-check.sh devops-first-pipeline:local
docker compose up -d
```

## Verify

Container health, response and non-root checks pass. Open localhost:8000, then docker compose down after the lab.

## Break, diagnose, recover

Temporarily map host 8001 to container 8000. The internal health check should still pass; your browser must use host 8001.
