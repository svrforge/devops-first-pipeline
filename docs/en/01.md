# 01 · DevOps mindset

[Course index](README.md) · [English](../en/01.md) · [தமிழ்](../ta/01.md)

## Understand

DevOps connects development and operations through shared ownership, small changes and feedback. A pipeline is useful only when its checks represent behavior users need. In this course you own one service from source to recovery. Shipping safely matters more than collecting tool names.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
python -m unittest discover -s tests -v
```

## Verify

All tests finish with OK. Identify which test proves that unknown routes return 404.

## Break, diagnose, recover

Change the greeting in app.py only. Observe a failing assertion. Restore the greeting before continuing.

## Check your understanding

Which is the strongest evidence that a change is safe?

1. A green badge with no tests
2. Checks of expected service behavior
3. A larger YAML file
