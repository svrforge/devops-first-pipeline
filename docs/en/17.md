## In simple words

Explain what the automatic checks do for one change. Start with the short explanation below. Read the new-word meaning, follow one part at a time, and try the activity only when the idea makes sense. You do not need to memorize a list of tool names.

Continuous integration verifies changes automatically. Our stable checks run on push and pull request: three Python versions and a real Docker build/smoke test. Course content and links are checked too. A passing badge only covers configured behavior and can still miss a requirement nobody encoded.
