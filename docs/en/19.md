# Day 19 — Jenkins: controller, agent and stages

[All days](README.md) · [Animated classroom](../../academy/index.html#day=19)

## The idea

Jenkins coordinates work on agents. The agent needs Git, Bash, Python and Docker for this Jenkinsfile. A controller container does not automatically supply all build tools. Use a dedicated learning agent because Docker daemon access is powerful.

## A familiar example

A dispatcher coordinates deliveries; the vehicle doing the work still needs fuel and tools.

## Walk through it

### 1. Checkout

The agent retrieves the intended source revision.

### 2. Test

It runs the same tests as GitHub CI.

### 3. Build

It creates an image tagged with the build number.

### 4. Verify

It runs the common container check, then cleans its build image.

## Try it yourself

Run from the repository root. Read comments and prerequisites first.

```bash

# Follow docs/JENKINS.md for a dedicated Linux agent.
```
