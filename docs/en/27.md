## In simple words

Explain what to do if a real credential is exposed. Start with the short explanation below. Read the new-word meaning, follow one part at a time, and try the activity only when the idea makes sense. You do not need to memorize a list of tool names.

Grant the minimum access needed, keep secrets outside source and do not confuse deleting a secret from a file with revoking it. A real exposed credential must be revoked or rotated. CI should avoid unnecessary write permissions and should not run untrusted changes with privileged secrets.

## Part 1: Inventory

Identify where credentials could enter a project: env files, logs, state and config.

**New word — Secret:** Sensitive information such as a password or access token.

**Example:** Removing a copied key from a photo does not change the lock it opens.
