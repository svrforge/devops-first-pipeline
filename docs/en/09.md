## In simple words

Explain the different jobs of DNS and HTTPS. Start with the short explanation below. Read the new-word meaning, follow one part at a time, and try the activity only when the idea makes sense. You do not need to memorize a list of tool names.

DNS translates a name into addressing information; it does not guarantee the destination is healthy. TLS protects a connection and authenticates a server name through certificates. A public endpoint adds exposure and responsibility. This local service intentionally has neither TLS termination nor authentication and should not be treated as a public production API.

## Part 1: Resolve

Use a name to identify the destination; do not confuse name resolution with service health.

**New word — DNS:** The system that helps turn a name into an address.

**Example:** A directory gives an address; a verified identity at the door is a separate check.
