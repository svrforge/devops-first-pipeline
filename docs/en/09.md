[Course index](README.md) · [English](../en/09.md) · [தமிழ்](../ta/09.md)

## Understand

A Deployment declares desired pods; a Service provides a stable route to selected pods. Readiness determines traffic eligibility; liveness can trigger restarts. Start with a local kind cluster to avoid cloud cost. Always specify context when changing cluster resources. This lab loads a local image and deliberately never pulls it from a registry.

## Try it

Run from the repository root. Commands are examples to run yourself; the learning CLI never executes them.

```bash
kubectl config current-context
# Follow docs/KUBERNETES.md for named-context commands.
```

## Verify

Two pods are Ready in kind-devops-learning and /health works through port-forward.

## Break, diagnose, recover

Skip image loading on a fresh lab cluster. Diagnose ErrImageNeverPull, load the image and verify rollout.
